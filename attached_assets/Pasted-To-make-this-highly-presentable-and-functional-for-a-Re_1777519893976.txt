To make this highly presentable and functional for a Replit demo without setting up a complex database, you can use Local Storage. This allows the "wallet" to remember the balance and rewards even if you refresh the page, without needing a backend.

Here is a prompt specifically designed for Replit Agent to build a polished, "no-code" style prototype.

The Replit Agent Prompt
Project Name: CampusPay Prototype
Objective: Create a high-fidelity, interactive single-page application (SPA) for a Student College Wallet.

1. "Hoax" Authentication:

Create a sleek, minimalist Login/Sign-up page.

Logic: Any username and password will work. Once "Login" is clicked, it sets a flag in Local Storage and redirects the user to the Dashboard.

2. Visual Aesthetic (The "Old Money" Modern Look):

Use Tailwind CSS for styling.

Palette: Deep Navy, Charcoal, and Champagne Gold accents. Use rounded corners (rounded-2xl) and soft shadows (shadow-lg) for a premium feel.

Use Lucide-react icons for the wallet, food, and print actions.

3. The Functional Dashboard:

Hero Card: A "Gold" gradient card showing a Starting Balance of ₹1,500 and 50 Reward Points.

Action Buttons: Three prominent cards:

Pay Fees: Opens a modal to "Pay Semester Fees" (Deducts ₹500, adds 10 points).

Print Lab: "Pay for Prints" (Deducts ₹20, adds 1 point).

Cafeteria: "Buy Meal" (Deducts ₹100, adds 5 points).

Interactive Logic: Use React State to update the balance and rewards instantly. Use a "Toast" notification (like Sonner or a simple div) to say "Payment Successful! +5 Points Earned."

4. The "Presentation" Features:

Transaction History: A scrollable list at the bottom showing recent activities (e.g., "Library Print - ₹20").

Rewards Progress: A progress bar showing how close the student is to a "Free Coffee" reward (at 100 points).

Responsive: Ensure it looks like a mobile app when viewed on a phone.

5. Technical Note:

Use localStorage to persist the wallet balance and transaction list so the demo doesn't reset on refresh.

Keep all code in a clean, modular React structure.

Why this works for your demo:
Zero Database Errors: Since the login is a "hoax," you won't run into "User not found" errors during a live presentation.

Instant Feedback: When you click "Buy Meal," the balance drops and rewards go up immediately. This "pop" is what impresses people during a demo.

Professional Look: By specifying the Navy/Gold color palette and Tailwind, the app will look like a high-end fintech product rather than a basic student project.
